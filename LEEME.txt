BUTAK V2 — WEB INSTALABLE PARA ANDROID

SUBIDA A GITHUB
1. Abre tu repositorio butak-web. (con punto final en el nombre).
2. Sube los archivos de ESTA carpeta DIRECTAMENTE a la raíz del repositorio (no subas la carpeta ni el ZIP).
3. Confirma con Commit changes. GitHub Pages ya está configurado para main / (root).
4. Espera a que se publique y abre https://elmataderodemorkay-code.github.io/butak-web./
5. En Chrome Android, menú ⋮ > Añadir a pantalla de inicio > Instalar aplicación (el texto puede variar).
6. Comparte ese enlace con tus amigos; cada uno debe instalarla desde Chrome.

INCLUYE
Catálogo, búsqueda, fichas detalladas, reparto, tráiler externo, recomendaciones, listas vistas/pendientes/favoritas, notas, críticas locales, ranking personal, estadísticas, juego de adivinar carteles, exportación/importación de datos.

LIMITACIONES
No es un APK: es una PWA instalable desde Chrome.
No hay cuentas, sincronización ni intercambio real de críticas/amigos. Los datos se guardan en el dispositivo/navegador; pueden perderse si se borran los datos del navegador. Exporta copias desde Mi perfil.
La conexión a TMDB necesita Internet. El aspecto de la web puede abrirse sin conexión tras la primera carga.
La opción de privacidad de críticas es preparatoria: ninguna crítica se publica ni se comparte.
La API existente de Cloudflare debe seguir operativa.
